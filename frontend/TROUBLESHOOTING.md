# MediCode 前端故障排查指南

## 常见问题

### 1. 页面闪烁或白屏

**原因**: Vite 缓存损坏

**解决方案**:
1. 运行 `bat\前端修复.bat` 清理 Vite 缓存
2. 清理浏览器缓存 (Ctrl+Shift+Delete)
3. 重新运行 `bat\一键启动.bat`

### 2. 端口占用

**原因**: 端口 3051 被其他程序占用

**解决方案**:
1. 运行 `bat\端口工具.bat` 检查端口占用
2. 选择「一键换端口」自动切换空闲端口
3. 或修改 `vite.config.ts` 中的端口号

### 3. 依赖问题

**原因**: node_modules 损坏或版本不兼容

**解决方案**:
1. 删除 `node_modules` 文件夹
2. 运行 `npm install`（或 `bat\一键安装.bat`）
3. 重新启动应用

### 4. 配置文件问题

**原因**: vite.config.ts 配置错误

**解决方案**:
1. 检查 `vite.config.ts` 文件是否存在
2. 确认代理配置正确
3. 检查插件配置

## 诊断与修复工具

### bat\前端修复.bat
自动修复常见前端问题：
- 清理 Vite 缓存
- 检查并清理端口占用
- 提供依赖重装指导

### bat\端口工具.bat
诊断与切换端口：
- 检查 Windows 保留端口段
- 查看当前端口占用
- 一键切换空闲端口

### bat\一键启动.bat
启动整个系统（后端 + 员工前端 + 患者前端）。

## 手动启动

如果批处理脚本无法使用，可以手动启动：

```bash
cd frontend
npm run dev
```
