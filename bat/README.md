# bat — Windows 双击入口

所有入口脚本统一放在本目录，双击即可运行。

| 文件 | 功能 |
| --- | --- |
| `一键启动.bat` | 一键启动：检测端口 → 清 Vite 缓存 → 改配置 → 启动后端 + 员工前端 + 患者前端 |
| `一键安装.bat` | 安装前后端依赖（Python + Node） |
| `初始化数据库.bat` | 初始化双数据库（调用 `scripts\database\init_databases.py`） |
| `端口工具.bat` | 检查 Windows 保留端口 / 查看占用 / 一键换端口 |
| `前端修复.bat` | 清理 Vite 缓存、终止占用端口的进程、依赖重装指导 |
