# 系统启动指南

> 无论你是开发者还是项目参与者，这份指南帮你把系统跑起来。
> 
> **当前版本**: v0.2.0 | **UI**: Google Material Design 3 | **主题**: 专业医疗风格

---

## 快速开始（5分钟）

### 前提条件检查

```bash
# Windows 用户在新终端中运行：
python --version     # 需要 Python 3.11 或更高
node --version       # 需要 Node.js 20 或更高
npm --version        # 需要 npm 10 或更高

# 如果没有安装，请先安装：
# Python: https://www.python.org/downloads/
# Node.js: https://nodejs.org/ (选择 LTS 版本)
```

### 启动后端

```bash
# 1. 进入后端目录
cd backend

# 2.（首次）安装依赖
pip install -r requirements.txt

# 3. 启动服务
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

看到以下输出表示成功：
```
==================================================
  医码合一智慧医疗系统 v0.1.0
==================================================
[初始化] 默认管理员已创建: admin / admin
[启动] 服务器运行在 http://0.0.0.0:18001
[启动] API文档: http://localhost:18001/docs
==================================================
```

### 启动前端

打开**另一个新终端**：

```bash
# 1. 进入前端目录
cd frontend

# 2.（首次）安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

看到以下输出表示成功：
```
  VITE v8.2.0  ready in xxx ms

  ➜  Local:   http://localhost:3051/
  ➜  Network: use --host to expose
```

> 💡 系统采用 **Google Material Design 3** 专业医疗风格 UI，字体使用 Outfit + Inter。

### 打开系统

```
1. 浏览器打开: http://localhost:3051
2. 账号: admin
3. 密码: admin
4. 登录后进入 Material 3 风格的控制台仪表盘
```

## Docker 部署（生产环境）

### 开发环境（推荐本地开发使用）

```bash
# 使用SQLite，无需额外数据库
docker-compose -f docker/docker-compose.dev.yml up -d

# 访问: http://localhost
# API文档: http://localhost:18001/docs
```

### 生产环境

```bash
# 使用PostgreSQL + MongoDB
docker-compose -f docker/docker-compose.yml up -d

# 查看运行状态
docker-compose -f docker/docker-compose.yml ps

# 查看后端日志
docker-compose -f docker/docker-compose.yml logs -f backend

# 重启某个服务
docker-compose -f docker/docker-compose.yml restart backend

# 全部停止
docker-compose -f docker/docker-compose.yml down
```

## MongoDB 安装（可选）

MongoDB 用于存储非结构化数据（训练数据、知识文档等），**不是系统运行必需的**。

```bash
# 方式一：Docker（推荐）
docker run -d \
  --name medical-mongo \
  -p 27017:27017 \
  -v mongo_data:/data/db \
  mongo:7

# 方式二：直接安装
# 下载: https://www.mongodb.com/try/download/community
# 安装后默认在 localhost:27017 运行

# 系统会自动检测MongoDB是否可用
# 不可用时：非结构化功能暂时禁用，核心功能不受影响
```

## 常见问题排查

### Q1: `ModuleNotFoundError: No module named 'xxx'`
```bash
# 依赖未安装完整，重新安装
cd backend
pip install -r requirements.txt
```

### Q2: `Address already in use` (端口被占用)
```bash
# 端口8000或3000已被其他程序占用
# 解决方案1：关闭占用端口的程序
# 解决方案2：使用其他端口启动
uvicorn app.main:app --reload --port 8001
```

### Q3: `npm install` 很慢或失败
```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com
npm install
```

### Q4: 前端页面打不开或空白
```
检查事项：
1. 后端是否正常启动？（打开 http://localhost:18001/docs 检查）
2. 前端开发服务器是否正常？（终端是否有报错）
3. 浏览器控制台是否有错误？（F12 → Console）
```

## 开发常用命令

```bash
# ===== 后端 =====
cd backend

# 启动（开发模式，代码修改自动重启）
uvicorn app.main:app --reload

# 重新初始化数据库（清空所有数据！）
rm data/medical_system.db
# 重启后端，自动重新创建

# 查看API文档
浏览器打开: http://localhost:18001/docs

# ===== 前端 =====
cd frontend

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 类型检查
npx tsc --noEmit

# ===== Docker =====
# 全部启动
docker-compose -f docker/docker-compose.yml up -d

# 查看日志
docker-compose -f docker/docker-compose.yml logs -f

# 重新构建并启动
docker-compose -f docker/docker-compose.yml up -d --build

# 停止并清理
docker-compose -f docker/docker-compose.yml down -v
```
