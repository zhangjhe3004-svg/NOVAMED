# MediCode 自动端口检测与分配功能

## 功能说明

系统支持自动检测空闲端口并自动分配，避免端口冲突导致启动失败。

## 工作原理

1. **端口检测**：检测默认端口（后端 18001、员工前端 3051、患者前端 3005）是否被占用
2. **自动分配**：如果端口被占用，自动切换到下一个端口
3. **配置更新**：自动更新配置文件中的端口和代理设置
4. **服务启动**：使用检测到的端口启动所有服务

## 使用方法

### 一键启动（推荐）

双击 `bat\一键启动.bat`，系统会自动：

- 检测并分配端口
- 清理 Vite 缓存
- 更新配置文件
- 启动后端、员工前端、患者前端
- 显示分配的端口和登录信息

### 单独切换端口

双击 `bat\端口工具.bat`，选择「一键换端口」，会调用：

```powershell
scripts\select_free_port.ps1
```

## 端口默认配置

- 后端：18001
- 员工前端：3051
- 患者前端：3005

## 配置文件更新

启动脚本会自动更新以下文件：

- `backend/app/core/config.py` - 后端端口和 CORS 配置
- `frontend/vite.config.ts` - 员工前端端口和代理目标
- `frontend/vite.patient.config.ts` - 患者前端端口和代理目标

## 注意事项

- 需要确保 Python 3.11 已安装
- 需要确保前端依赖已安装（运行 `bat\一键安装.bat`）
- 配置文件会被直接修改，建议使用版本控制管理
