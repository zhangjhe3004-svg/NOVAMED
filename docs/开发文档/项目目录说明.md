# MediCode · 项目目录组织说明

> 目标：根目录只保留“入口 + 核心目录 + 配置”，文档统一归入 `docs/` 并按「使用 / 开发」分类，业务配置 json 集中到 `config/`，数据库 SQL 统一到 `db/`。

## 推荐目录结构（2026-09-14 重组后）
```
MediCode/
├── CLAUDE.md                # Agent 桥接（留在根目录，Claude 自动读取）
├── config/  ★               # 业务配置集中
│   └── agent_config.json    # AI Agent 配置（运行时加载，含诊断工作流编排）
├── db/  ★                   # 数据库表结构 SQL
│   ├── 患者数据库.sql
│   └── 员工数据库.sql
├── docs/  ★                 # 文档总目录（全部 md）
│   ├── 使用文档/            # 面向使用者
│   │   ├── 使用教程.md
│   │   ├── startup-guide.md
│   │   ├── troubleshooting.md
│   │   └── 端口说明.md
│   └── 开发文档/            # 面向开发者
│       ├── 技术文档.md
│       ├── 未完成功能.md
│       ├── 技术栈与实现.md
│       ├── 项目目录说明.md   # 本文
│       ├── 员工域低代码设计方案.md
│       ├── nocobase-style-architecture.md
│       ├── tech-explained.md
│       ├── ai-training.md
│       └── ai-anti-hallucination-tutorial.md
├── scripts/  ★               # 数据库初始化脚本 / 插件安装脚本
│   ├── init_databases.py
│   ├── install_all_marketplace_plugins.ps1
│   └── plugin_install_log.txt
├── docker/  ★                # Docker 配置文件
│   ├── docker-compose.yml
│   └── docker-compose.dev.yml
├── bat/  ★                   # 精简后 4 个脚本
│   ├── 一键启动.bat          # 启动后端+员工端+患者端；端口冲突时提示一键换端口
│   ├── 一键安装.bat          # 装 Python + Node 依赖
│   ├── 初始化数据库.bat      # 重建双库
│   └── 端口工具.bat          # 检查端口 / 一键换端口
├── Port/                    # select_free_port.ps1（被 bat 调用）

│       ├── medical_system.db(旧单库，兼容) / patient.db / employee.db / uploads
└── frontend/                # 前端
```

## 分类说明
| 类别 | 位置 | 内容 |
|------|------|------|
| 业务配置 json | `config/` | `agent_config.json`（运行时加载） |
| 工程/工具 json | 各自原位 | `frontend/package.json`、`tsconfig*.json`、`.vscode/`、`.claude/`、`.oxlintrc.json` 等（不可移动） |
| 文档（全部） | `docs/` | 使用文档与开发文档分开 |
| 启动脚本 | `bat/` | 4 个；`Port/` 放端口选择工具 |

## 数据文件存放位置
| 类型 | 位置 |
|------|------|
| 患者库（运行） | `backend/data/patient.db` |
| 员工库（运行） | `backend/data/employee.db` |
| 旧单库（兼容） | `backend/data/medical_system.db` |
| 上传附件/报告 | `backend/data/uploads` |
| 向量库 | `services/vector_db.py`（NumPy/FAISS 内存/磁盘） |

## 生成/导入流程
1. 编辑 `db/患者数据库.sql`、`db/员工数据库.sql`。
2. 运行 `python scripts/init_databases.py`（或 `bat\初始化数据库.bat`）→ 生成 `backend/data/patient.db`、`employee.db`。
