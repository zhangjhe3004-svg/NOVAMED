# AI 防幻觉体系 · 使用教程

> 医码合一全域智慧医疗系统 · AI 辅助诊断（防幻觉增强版）
> 配置源：项目根目录 `config/agent_config.json`

本教程带你从启动、配置到看懂一次完整的"防幻觉诊断"，并解释每一项结果的背后含义。

---

## 一、这套"防幻觉体系"是什么

系统采用验证专家风格的 Agent 配置，核心是**绝不让 AI 编造没有依据的结论**。现在每一次 AI 诊断，都会按下面这条流水线走：

```
症状输入
  ↓ ① 规则引擎：症状关键词 → 候选诊断
  ↓ ② 相似病例：混合搜索（SQL + 向量）历史病例，投票修正
  ↓ ③ 知识库：检索诊疗指南/药品说明作为引用依据
  ↓ ④ 防幻觉验证层：
       证据分级 → 引用核查 → 撤回兜底 → 医生确认门控
  ↓ ⑤ 输出：带【引用证据定位】+ 置信度 + 【待医生确认】的诊断建议
```

第 ④ 步是本次新增的核心，它确保：**每条诊断都"有据可查"**；找不到依据的主张会被撤回；证据不足时直接说"我不知道/建议进一步检查"，绝不硬凑。

## 二、快速启动

### 2.1 后端

```bash
cd backend
pip install -r requirements.txt        # 首次
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

验证：浏览器打开 http://localhost:18001/docs ，能看到接口文档（含新增的 `GET /api/ai/config`、`POST /api/ai/analyze`）。

### 2.2 前端

```bash
cd frontend
npm install                             # 首次
npm run dev
# 浏览器打开 http://localhost:3051
```

### 2.3 登录

默认账号：**admin / admin**

登录后点击左侧 **AI 辅助诊断** 或 **系统设置**。

## 三、配置云端 AI 服务商（可选，用于"深度分析"）

> 说明：不配置也能用。默认走**本地验证引擎**，完全离线、隐私最好。只有当你想要"思维链 CoT 深度分析"时，才需要配 API Key。

1. 进入 **系统设置 → AI 服务商配置**。
2. 选择一家服务商，粘贴你的 API Key，点 **保存**。支持：OpenAI、DeepSeek、通义千问、Claude。
   - Key 安全存储在服务器端 `backend/.env` 文件。
3. 保存后，上方 **AI 服务商状态** 卡片会显示已配置的服务商；AI 诊断页的"分析引擎"下拉框也会出现云端选项。

> 断网或 Key 失效时，系统会自动回退到本地验证引擎，不会崩溃。

## 四、使用：本地验证引擎（默认，离线）

1. 打开 **AI 辅助诊断**。
2. 可选：关联患者（会带入既往病史，增强分析）。
3. 在 **分析引擎** 保持选择 `本地验证引擎（离线防幻觉）`。
4. 输入症状描述，例如：`患者头痛3天，右侧太阳穴搏动性疼痛，伴恶心、畏光`。
5. 点 **开始 AI 分析**。

返回结果里你会看到（关键看防幻觉那几块）：

- **每条诊断卡片** 左下多出：
  - **证据等级**：`A / B / C`（对应证据强弱，见下文）。
  - **风险等级**：`高/中/低`。
  - **待医生确认**：紫色标签，提醒这只是 AI 建议。
  - **引用证据定位**：这条诊断到底是凭什么下结论的，逐条列出。
- **页面底部"防幻觉验证摘要"卡片**：
  - 状态：`证据校验通过` 或 `证据不足`。
  - **已撤回的主张**：如果某候选诊断找不到支撑性引用，会列在这里（说明它被"撤回了"，不会出现在诊断列表里）。
  - 已启用的防幻觉机制清单。

### 怎么读"引用证据定位"

例：
```
【引用证据定位】
[症状原文] "患者头痛3天，右侧太阳穴搏动性疼痛，伴恶心、畏光" 命中典型症状：头痛、恶心、畏光
[患者病史] "患者有类似诊断史"
```

- `[症状原文]` = 你输入的症状里命中了哪些关键词。
- `[相似病例]` = 数据库里哪条历史病例支持该诊断。
- `[知识库]` = 哪篇诊疗指南/文档支持。
- `[患者病史]` = 既往诊断/过敏史支持。

依据越多、越权威 → 证据等级越高（C < B < A）→ 置信度越高。

## 五、使用：云端 CoT 深度分析（可选）

1. 确保已配置至少一家服务商（见第三节）。
2. 在 **分析引擎** 选择 `云端 openai（CoT）` 或 `云端 自动选择`。
3. 输入症状，点 **开始 AI 分析**。

这次会调用外部大模型，用 **低温 0.2 + 防幻觉提示词** 做一次完整的 **思维链（CoT）鉴别诊断**：
- 返回结果里会多出一张 **"AI 深度分析（思维链 CoT）"** 卡片，展示模型的逐步推理。
- 其余防幻觉字段（证据等级、引用、撤回、待医生确认）依然保留。
- 若云端调用失败，右侧下方会提示"将使用本地验证引擎"，结果自动回退。

## 六、结果字段速查

| 字段 | 含义 |
|------|------|
| `engine` | 本次使用的引擎：`local` / `cloud_cot` |
| `diagnoses[].evidence_tier` | 证据等级 A/B/C（A 最强，C 最弱） |
| `diagnoses[].risk_level` | 风险等级 高/中/低 |
| `diagnoses[].citations` | 引用证据定位列表 `[{source, quote}]` |
| `diagnoses[].confirmation_required` | 是否需医生确认（恒为 true） |
| `verification.verification_status` | `confirmed`（通过） / `uncertain`（证据不足） |
| `verification.retracted_claims` | 被撤回的主张列表 |
| `verification.unknown_fallback` | "我不知道/建议进一步检查"提示 |
| `verification.rules_applied` | 已启用的防幻觉规则清单 |
| `ai_analysis` | 云端 CoT 深度分析文本（仅云端路径） |

## 七、防幻觉机制 · 对照表

| 机制 | 说明 | 在哪里生效 |
|------|------|-----------|
| 思维链 CoT | 逐步展示推理，暴露错误逻辑 | 云端深度分析 |
| 思维树 ToT | 多分支鉴别诊断路径探索 | 云端深度分析（探索阶段 temp 0.6） |
| 引用验证 | 每条诊断标注来源并核实 | 本地验证层 + 云端 |
| 直接引用要求 | 保留的事实用直接引用支持 | System Prompt |
| 证据分级 | C < B < A，置信度与证据匹配 | 本地验证层 |
| 撤回兜底 | 找不到支撑性引用即撤回 | 本地验证层 |
| 未知兜底 | 无法确定返回"我不知道/建议检查" | 本地验证层 |
| 自洽性检查 | 多次采样对比，不一致触发回溯 | 云端（best_of_n=5） |
| 医生确认门控 | 所有输出标注【待医生确认】 | 本地验证层 + 云端 |
| 低温参数 | temperature 0.2 / repetition 1.2 | 云端调用 |

## 八、参数说明（在设置页可见）

| 参数 | 值 | 作用 |
|------|-----|------|
| `temperature` | 0.2 | 低温保障事实输出稳定，降低幻觉 |
| `top_p` | 0.9 | 核采样（验证阶段自动收紧到 0.6） |
| `repetition_penalty` | 1.2 | 中文重复惩罚，略高于英文，抑制重复 |
| `min_p` | 0.05 | 过滤低概率噪声词，从根源减幻觉 |
| `seed` | 42 | 固定随机种子，结论可复现 |
| `max_tokens` | 4096 | 单次输出上限 |

**探索 / 验证双档**：
- 探索档（ToT 多方案）：`temp 0.6`
- 验证档（引用核查）：`temp 0.1`
- 默认基准：`temp 0.2`

> 系统按输入规模自动切换：长病历（>20k token）进探索档，常规任务进验证档。你不需要手动调。

## 九、常见问题 FAQ

**Q1：为什么某个可能的诊断不见了？**
被防幻觉层"撤回"了——它没有找到支撑性引用。请看底部"已撤回的主张"列表，它在被撤回前已列明原因。

**Q2：为什么返回"我不知道 / 建议进一步检查"？**
说明当前症状证据不足，无法给出可靠诊断。按提示补充检查结果后复诊即可。这是防幻觉机制在起作用，而不是系统坏了。

**Q3：选了云端却还是本地结果？**
可能原因：① 未配置该服务商 Key；② 调用失败（断网/额度不足），系统已自动回退本地；③ 前端提示"将使用本地验证引擎"。

**Q4：置信度比之前低？**
正常。防幻觉层按证据等级校准了置信度：仅症状原文支持（C 级）的诊断，置信度会被压低（≤0.55），避免过度自信。

**Q5：在哪里看当前防幻觉配置？**
系统设置 → **"AI 防幻觉配置"** 卡片，可看到角色、生成参数、场景参数剖面、防幻觉机制与证据分级。

## 十、开发者接口速览

| 接口 | 用途 |
|------|------|
| `POST /api/ai/diagnose` | 本地验证引擎（含防幻觉验证） |
| `POST /api/ai/analyze` | 云端 CoT 深度分析，失败自动回退本地 |
| `GET /api/ai/config` | 查看防幻觉 Agent 配置摘要 |
| `GET /api/ai/providers` | 已配置的云端服务商 |
| `GET /api/ai-keys` | API Key 配置状态（脱敏） |

前端已支持的可视化字段：`diagnoses[].evidence_tier`、`diagnoses[].citations`、`verification.retracted_claims`、`verification.unknown_fallback`、`ai_analysis`。
