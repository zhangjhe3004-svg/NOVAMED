# MediCode UI 设计预览

本目录为离线交互原型，不修改正式系统，不调用真实 API。所有人物、病历、地点及统计均为虚构数据。

## 打开方法

直接双击本目录的 HTML 文件即可在浏览器使用，无需安装依赖：

- `login.html`：员工登录与患者登录，可切换身份，点击“使用演示身份进入”。
- `index.html`：员工控制台、患者管理、医生工作台，以及手机外观展示。
- `patient.html`：完整患者端，包含首页、预约、就诊记录和个人中心；支持桌面和手机布局。

员工登录的演示入口进入控制台；患者登录的演示入口进入独立患者端。登录输入不上传、不保存，不应输入真实凭证。

## 文件说明

- `00-UI设计总览.png`：员工登录、患者登录、患者首页和预约页的组合效果图。
- `01` 至 `14` 的 PNG：浏览器实际渲染截图。
- `../开发文档/MediCode系统优化方案与执行手册.docx`：完整 Word 方案。
- `../开发文档/MediCode系统优化方案.md`：文档内容源文件。
- `tools/build-document.py`：使用 python-docx 重新生成 Word 与总览图。
- `tools/verify-preview.cjs`：浏览器交互与布局检查，并生成截图。
- `document-validation.json`：Word 包完整性、内容和嵌入图片检查结果。

生成工具使用本机的 Codex Python/Node 依赖路径；换电脑运行时需要调整这些工具路径。HTML 原型本身不依赖这些工具，可以直接打开。

## 已验证内容

员工与患者登录切换、空值提示、密码显示切换、患者登录跳转；患者检索与重置；工作台选择与草稿反馈；预约日期/时段选择及确认；患者记录与个人中心；390px 窄屏无整页横向溢出；未发现 JavaScript 运行异常。

这些是原型验证结果。真实服务的身份隔离、预约并发、数据库事务和生产性能仍按 Word 手册中的工单实施与验收。

Word 已通过文件包完整性检查与重新读取验证。生成环境未进行 Microsoft Word/WPS 的实际分页渲染，打开后的分页以文档阅读器为准。
